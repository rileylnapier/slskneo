# Third-party software

Soulseek Studio is an independent client; it is not an official Soulseek release.

- **aioslsk 1.6.4** — Soulseek protocol implementation, GPL-3.0-or-later.
  https://github.com/JurgenR/aioslsk
- **MCP Python SDK 1.30.0** — MCP transport and server, MIT.
  https://github.com/modelcontextprotocol/python-sdk
- **Electron 45.0.0** — desktop shell, MIT with bundled Chromium and Node notices.
  https://github.com/electron/electron
- **React 19.3.1** — interface, MIT. https://github.com/facebook/react
- **Lucide** — interface icons, ISC. https://github.com/lucide-icons/lucide
- **Python, PyInstaller, and supporting packages** — packaged with their
  respective licenses. Exact versions are recorded in the lock files.

The application source is supplied in this workspace. REA and Ghidra were used
for local analysis and are not bundled in the desktop application. Decompiled
SoulseekQt pseudocode is investigation evidence and is not compiled into the app.
